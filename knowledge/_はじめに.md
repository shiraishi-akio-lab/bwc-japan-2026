# 営業GYMの知識の保管庫

この保管庫を Obsidian で開いて書きます。アプリは、ここに書いた Markdown を `npm run knowledge` で JSON に変換して読みます（`data/` の JSON は生成物なので直接編集しない）。

すべて架空の会社・人物・数字です。実在の企業・店舗・人物・地域を思わせる名前や数字は書かないでください。

## フォルダ
| フォルダ | 中身 | 誰が書くか |
|---|---|---|
| `rubric/` | 物差しの5つの軸（1軸＝1ファイル） | 人 |
| `cards/` | ケースカード＝ベテランの判断の記録（1件＝1ファイル） | 人。承認済みだけをここに置く |
| `cards/_pending/` | ケースカードの候補 | 整理する係（Claude）の下書き。人が読んで `cards/` に移し、`status: approved` にすると根拠として使われる |
| `eval/` | 評価セット。各場面の「正解」 | バイヤー側の経験者（オーナー） |

## ケースカードの書き方
先頭の `---` の間に id・タイトル・状態・場面・軸を書き、本文は次の見出しを順に埋めます：状況／仮説／根拠／提案／制約／結果／次の判断／退けた案。
退けた案は `- **案**：退けた理由` の形で書きます。見出しが空のまま、または物差しに無い軸を書くと、変換が止まって知らせます。

## 評価セットの書き方
「見落とした前提」「軸」「次の一手」の3つを埋めます。軸は customer / evidence / hypothesis / feasibility / dialogue から1つ（迷う場面は2つまで、カンマ区切り）。
